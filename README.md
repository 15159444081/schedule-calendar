# 日程系统 · 运行说明

## 它是什么

一个三层日历（月 / 周 / 日）＋ 本地数据服务。
数据是 Obsidian 库里的普通 Markdown 文件，所以：**Obsidian 能看、AI 能直接读写、网页能实时显示**。

## 怎么用

1. 双击 `D:\ai产物\日程表\日程表1022\启动.vbs`
2. 浏览器开 <http://127.0.0.1:8770>
3. 手机（同一个 WiFi）开 `http://<电脑局域网IP>:8770`

查局域网 IP：命令行执行 `ipconfig`，看「IPv4 地址」，一般是 `192.168.x.x`。

> 第一次手机连不上，多半是 Windows 防火墙拦了。
> 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾上 Python 的「专用网络」。

## 交互

| 操作 | 效果 |
|---|---|
| 顶栏 `‹` `›` | 上一个/下一个 月、周、日（跟着当前视图） |
| 点月视图里某一天 | 钻进那一天（日视图） |
| 点月视图格子右上角 `W43` | 钻进那一周（周视图） |
| 点周视图的日期表头 | 钻进那一天 |
| 点周/日视图的空白时间格 | 在那个时间点新建日程 |
| 点已有日程块 | 编辑 / 删除 |
| 点日视图右侧的待办 | 勾掉 / 取消 |
| 「今天」 | 回到今天 |
| 每 30 秒 | 自动重新拉数据（别的设备改了会自己更新） |

## 数据同步怎么落地

日历本身不存数据，**数据在 md 文件里**。所以同步 = 让这个文件夹在手机和电脑之间同步。三条路，按需选：

- **A. 只在局域网用（现在可用，零成本）**：手机浏览器直接连电脑的 8770 端口，同一 WiFi 下延迟毫秒级。
- **B. 手机装 Obsidian + Remotely Save 插件**（免费，支持坚果云/OneDrive WebDAV）：手机上也能直接看/改 md，改动回到电脑后网页自动刷新。适合外出。
- **C. 外网访问网页**：给 8770 端口做内网穿透（Cloudflare Tunnel / tailscale），人在外面也能直接开日历界面。配置麻烦一些。

框架现在跑通的是 A。B、C 等确定需求后再接。

## 密码与安全

- **本机（127.0.0.1）不用密码**，你在这台电脑上直接开就行。
- **别的设备访问要登录**：用户名和密码写在 `auth.json` 里，首次启动会自动生成一个随机密码。
- 改密码：编辑 `auth.json`，改完立刻生效，不用重启服务。
- 认证方式是 HTTP Basic——浏览器会弹系统自带的登录框，输一次通常就记住了。
- 局限：HTTP 是明文，同一个 WiFi 里如果有人专门抓包，能看到密码和内容。挡住「随手扫端口的邻居」够用，别当成银行级加密。

## 端口 / 环境变量

- 端口默认 `8770`，改 `server.py` 顶部 `PORT`。
- 数据目录默认 `D:\Obsidian笔记库\日程`，可用环境变量 `SCHEDULE_VAULT` 覆盖。
- 只有一个第三方依赖：**没有**。纯 Python 标准库。

## 常见问题

**页面显示「连接失败」** → server.py 没在跑，双击 `启动.vbs`。

**改了 md 网页没变** → 等 30 秒自动刷新，或按 F5。

**想让它在开机时自动跑** → 把 `启动.vbs` 的快捷方式放进
`C:\Users\I\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`
